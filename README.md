# Business Metrics für Designer

Ein interaktiver Lernkurs für Designer, die Business Metriken verstehen und in Stakeholder-Gesprächen einsetzen wollen.

## Was ist das?

Eine Single-Page-App ohne Build-Step, ohne Framework, ohne Dependencies. Eine HTML-Datei, direkt im Browser öffnen.

Der Kurs deckt die 8 wichtigsten Metrik-Kategorien ab — von Conversion Rate bis LTV:CAC — mit Erklärungen, Formeln, Rechenbeispielen und einem Quiz am Ende jeder Lektion. 80% zum Bestehen.

## Inhalt

| Lektion | Thema |
|---|---|
| 1 | Warum Designer Business Metrics kennen müssen |
| 2 | Conversion Rate |
| 3 | Activation Rate & Time-to-Value |
| 4 | Retention Rate & Churn |
| 5 | MRR, ARR & Revenue-Wachstum |
| 6 | LTV und CAC — die wichtigste Ratio |
| 7 | NPS, CSAT & Feature Adoption |
| 8 | Cheat Sheet & Argument-Templates |

## Nutzung

```bash
# Einfach öffnen
open business-metrics-for-designers.html
```

Kein Server, kein npm, kein nichts. Funktioniert offline.
